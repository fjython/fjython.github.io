FAQ

What Markdown features does this preview support?

A common subset: ATX headings (# through ######), bold and italic, inline code and fenced code blocks, links, unordered and ordered lists, blockquotes, horizontal rules, and paragraphs. Tables and raw HTML are not rendered as markup.

Is my Markdown uploaded to a server?

No. Parsing and preview run locally with JavaScript in your browser. Nothing is sent to a server.

Is the HTML output safe to paste into a page?

The converter escapes HTML special characters in your Markdown before applying formatting, so typed angle brackets become entities instead of live tags. Still review the HTML before using it in production.
