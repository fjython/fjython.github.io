FAQ

What does this URL encoder do?

Encode uses encodeURIComponent, which percent-encodes characters that are not safe in a query component, including spaces, &, =, ?, /, and non-ASCII text as UTF-8. Decode reverses those %HH sequences.

Is my text uploaded to a server?

No. Encoding and decoding run locally with JavaScript in your browser. Nothing is sent to a server.

Why does a plus sign become a space when I decode?

Query strings from HTML forms (application/x-www-form-urlencoded) use + for a space. Decode treats each + as a space before decodeURIComponent. A literal plus that was encoded as %2B stays a plus. Invalid sequences such as %ZZ show an error instead of a partial result.
