FAQ

Is my text uploaded to a server?

No. SHA-256 uses the Web Crypto API in your browser. MD5 is computed with a small local script. Nothing leaves your device.

Should I use MD5 for passwords?

No. MD5 is broken for security use. Prefer SHA-256 (or stronger) for integrity checks, and a dedicated password hasher (like bcrypt or Argon2) for storing passwords.

What encoding is used?

Input is treated as UTF-8 text. The output is a lowercase hexadecimal digest.
