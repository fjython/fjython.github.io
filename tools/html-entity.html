HTML Entity Encoder

Escape text into HTML entities or unescape entities back into characters. Markup characters and common symbols use named entities; other non-ASCII characters use numeric references. Everything runs in your browser.

FAQ

What does this HTML entity encoder do?

Escape turns &, <, >, ", ', and other special characters into named entities such as &amp; and &nbsp;, or numeric references such as &#233;. Unescape turns those entities back into characters.

Is my text uploaded to a server?

No. Escaping and unescaping run locally with JavaScript in your browser. Nothing is sent to a server.

Which entities can this tool decode?

It decodes common named entities such as &amp;, &lt;, &gt;, &quot;, &apos;, and &nbsp;, plus decimal references like &#169; and hexadecimal references like &#xA9;. Unknown entity names are left unchanged. An invalid numeric reference shows an error instead of a partial result.
